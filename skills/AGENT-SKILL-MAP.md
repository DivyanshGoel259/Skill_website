# Vanna Protocol — Agent ↔ Skill Mapping

> **How this works:** Every agent in the Vanna Protocol dashboard has a set of skills mapped to their role. When an agent is activated, starts a task, or communicates — the skills listed under their profile are automatically invoked to enhance their capabilities. Each agent inherits **core skills** (shared by all) + **role-specific skills**.
