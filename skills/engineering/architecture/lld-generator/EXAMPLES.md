## Key Differences Between Template and Code-Based LLDs

### Template LLD Characteristics:
- Contains placeholder text: `[Project Name]`, `[To be determined]`
- Empty or example tables for user to fill in
- Generic guidance in sections
- Focus on structure and format
- Requires manual completion

### Code-Based LLD Characteristics:
- Actual resource names extracted from code
- Real IP addresses and configurations
- Specific SKUs, sizes, and settings
- May have `[To be determined]` for items not in code
- Includes validation notes
- References source code location
- Documents actual deployed state
- Notes sections requiring manual completion

---

## Tips for Using Generated LLDs

1. **Template LLDs**: Use as starting point for new projects, fill in all bracketed placeholders
2. **Code-Based LLDs**: Review for completeness, add manual sections (policies, RBAC, monitoring)
3. **Validation**: Always check naming against naming-convention.md and IPs against ip-addressing-scheme.md
4. **Customization**: Feel free to add sections specific to your project needs
5. **Maintenance**: Update LLD when infrastructure changes to keep documentation current
